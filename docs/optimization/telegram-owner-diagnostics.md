# Диагностика Telegram в личке владельца

Срез задачи 2 фазы 4. Личное уведомление о сбое содержит безопасный код и идентификаторы
запроса и запуска. Если до сбоя сервер записал успешные операции, уведомление показывает
их количество и предупреждает о повторном запросе. Источником служат события инструментов
этого запуска. Сбой отправки уведомления не повторяет выполненные операции.

`/errors` показывает до 20 последних сохранённых записей личного AI, Guest Mode и
автоответчика. Команда проходит ту же проверку привязанного Telegram ID, что остальные
личные команды. В группу и собеседнику диагностика не отправляется.

Автоответчик показывает причины передачи вложения владельцу и сохраняет код причины.
Если формирование автоматического ответа завершилось ошибкой, уведомление получает
владелец. Необработанные тела ответов провайдеров, сообщения собеседников и ключи не
включаются в диагностику. У старых записей с общим кодом нельзя восстановить детали,
которые сервер ранее не сохранял.
