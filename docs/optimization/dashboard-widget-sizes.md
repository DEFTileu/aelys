# Dashboard: размеры виджетов

Задача из `IMPLEMENTATION_PLAN.md`: Phase 3, Dashboard / personal modules.
Запрос владельца от 2026-10-31: адаптировать каждый виджет к размерам
1×1, 1×2, 1×3, 2×1, 2×2, 2×3.

## Поведение

- Размер обозначает ширину × высоту в ячейках. Строка — 176 px,
  промежуток — 16 px; высоты карточек — 176, 368 и 560 px.
- Все десять виджетов поддерживают шесть форматов. На desktop сохранён
  дополнительный 4×1 для совместимости с прежним Full width.
- Выбор доступен в Customize на desktop и Customize Home / Widgets на mobile.
  Desktop также поддерживает resize указателем и стрелками клавиатуры.
- Списки показывают 2/6/10 записей по высоте; компактные финансы — баланс
  и одну операцию. Расчёт денежных значений остаётся десятичным.
- Таймер, прогноз, заголовки и число колонок содержимого адаптируются
  к размеру самой карточки через CSS container queries. Избыточные данные
  можно прокрутить внутри карточки.
- Preview изменения размера обновляет содержимое; Escape / pointercancel
  восстанавливают размер и содержимое без записи в storage.
- Раскладки desktop/mobile независимы. При отсутствии v2 читается v1:
  Small → 1×1, Wide → 2×1, Large → 2×2, Full width → 4×1.
  Порядок и состав сохраняются. v2 записывается при следующем изменении,
  исходный v1 остаётся доступен.

## Предположения и OPEN

Владелец явно разрешил изменение UI в рамках этой задачи. Высота ячейки —
деталь реализации существующей сетки. Новых архитектурных решений нет;
статусы OPEN / PROPOSED не изменены. API, модель данных и серверные миграции
не затронуты: раскладка, как и прежде, хранится локально.

## Изменённые области

- `homeLayout.ts`, `WidgetFrame.tsx`, `HomeView.tsx`: размеры, перенос v1,
  сохранение и resize с preview / отменой.
- `homeWidgets.tsx`, `home-widgets.css`, `Weather.tsx`: адаптивное содержимое.
- `styles.css`, `actual-shell.css`, `main.tsx`: единая геометрия desktop/mobile.
- `MobileCustomizeView.tsx`, `mobile-customize.css`: шесть размеров для каждого
  виджета, раскладка кнопок в два ряда.
- `dashboard-layout.test.tsx`, `mobile-customize.test.tsx`: регрессионные тесты.

- `pnpm --filter @aelys/web test` — PASS: 47 файлов, 290 тестов.

  Снимки desktop, mobile и режима редактирования просмотрены вручную.
- Стенд и снимки находятся в игнорируемых `output/playwright/`; в production

набор размеров в Tauri WebView.
