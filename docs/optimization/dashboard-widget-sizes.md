# Dashboard: автоматические размеры виджетов

Задача из `IMPLEMENTATION_PLAN.md`: Phase 3, Dashboard / personal modules.
Запрос владельца от 2026-10-31: шесть форматов 1×1…2×3; уточнение —
адаптироваться сразу, без ручного выбора каждого размера.

## Поведение

- Все виджеты по умолчанию работают в Auto. `ResizeObserver` измеряет доступную
  ширину самой сетки: изменение окна или места под sidebar пересчитывает число
  колонок, без необходимости менять настройки.
- Пустые, загружающиеся и недоступные списки занимают одну строку. Списки с
  3–6 записями занимают две строки; с большим количеством — три. Ширина также
  зависит от доступного места и количества записей. На узком телефоне Focus
  получает полную ширину, чтобы сохранить доступность управления.
- Weather автоматически показывает подробный вариант при наличии прогноза;
  без прогноза остаётся компактным. Содержимое дополнительно адаптируется
  через существующие container queries.
- Строка — 176 px, промежуток — 16 px; высоты — 176, 368 и 560 px.
  Списки показывают до 2/6/10 записей; компактные финансы — баланс и одну
  операцию. Денежные расчёты остаются десятичными.
- Customize позволяет по желанию закрепить один из шести размеров или 4×1
  на desktop. Auto возвращает автоматический подбор. Resize указателем и
  клавиатурой закрепляет размер; Escape / pointercancel отменяют preview.
- Layout v3 хранит `[widgetId, 0]` для Auto и положительный span для ручного
  выбора. Автоматически вычисленные размеры не записываются в storage.
- Desktop/mobile остаются независимыми. v1/v2 читаются с сохранением порядка,
  состава и удалений; их размеры переходят в Auto по уточнению владельца.
  Исходные ключи сохранены. Ручной выбор в v3 сохраняется при перезапуске.

## Изменённые области

- `homeLayout.ts`: v3, Auto по умолчанию и перенос v1/v2.
- `automaticWidgetSize.ts`: типизированный расчёт по ширине и данным.
- `HomeView.tsx`: наблюдение за шириной контейнера и применение размеров.
- `WidgetFrame.tsx`: Auto в picker, возврат к автоподбору.
- `MobileCustomizeView.tsx`, `mobile-customize.css`: Auto и на мобильном.
- `automatic-widget-size.test.ts`, `dashboard-layout.test.tsx`,
  `mobile-customize.test.tsx`: размеры, обновление по ResizeObserver, перенос,
  сохранение ручных размеров и возврата к Auto.
- `SELF_HOSTING.md`: актуальное описание поведения.

## Предположения и OPEN

Владелец явно разрешил изменение UI в рамках Dashboard. Переход прежних размеров
к Auto сохраняет состав и порядок виджетов; старый storage не удаляется.
OPEN / PROPOSED статусы не менялись. API, база данных и серверные миграции
не затронуты: это существующие локальные настройки интерфейса.
