# Projects: реальный контекст проекта

Готовый текст для одного `/goal` (вставить весь блок ниже).

```text
Работай в <repository-root>.
Цель: Projects: реальный контекст проекта.
Милestone: Phase 1 task 4: Project CRUD/resource links — UX-срез.

Прочти docs/goals/UX_RULES.md и docs/UX_RESEARCH.md, затем обязательные документы из AGENTS.md. Соблюдай их в течение всей цели. Владельцем уже разрешены UI/UX-переработка этого среза и до шести субагентов; делегируй только независимые файлы.

Сделай карточки Projects входом в реальный контекст: выбор проекта открывает detail с описанием, статусом и связанными задачами/заметками/событиями из поддерживаемых API. Действия переименовать/архивировать/редактировать имеют работающий интерфейс; карточечное троеточие больше не декоративное. Поиск/фильтр реально действуют. Прогресс считают подтверждённые task data; при ошибке загрузки показывай неизвестный прогресс, а не 0%. Из проекта можно открыть связанный модуль с понятным контекстом; не придумывай отношения, которых нет в resource contracts. Сохрани внешние Git references без чтения произвольной host filesystem. Не расширяй Mac grants и не запускай агентов.

Критерии завершения:
Создать проект, открыть, изменить/архивировать, reload; ссылка на существующую задачу работает. Частичная ошибка загрузки не выдаёт ложные 0%/empty success. 409/ownership errors сохранены. Keyboard/узкий экран/быстрый возврат к списку проверены. Relevant API/resources/web tests и build проходят.

Доведи реализацию до функционально доступной локальной версии; не заканчивай только планом или макетом. В конце дай короткий отчёт с файлами, командами и точными результатами тестов, browser screenshot, ограничениями и следующей целью. Не запускай следующую цель автоматически.
```
