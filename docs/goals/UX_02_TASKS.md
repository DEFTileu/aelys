Работай в <repository-root>.
Цель: Tasks: быстро добавить и полноценно отредактировать.
Милestone: Phase 2: Tasks CRUD — один UX-срез поверх имеющегося API.

Сохрани существующий честный offline-status; полноценный replay/sync — отдельная цель.

Критерии завершения:
В браузере создать задачу без даты, найти её, задать дату/priority/project/description, обновить страницу, завершить и открыть снова. Поля сохранены через реальные API. Ошибки 409/сети не стирают редактор и не рисуют ложный успех. Нет декоративного троеточия без действия. Проверены keyboard и мобильный viewport, существенные tests/typecheck/build.

Доведи реализацию до функционально доступной локальной версии; не заканчивай только планом или макетом. В конце дай короткий отчёт с файлами, командами и точными результатами тестов, browser screenshot, ограничениями и следующей целью. Не запускай следующую цель автоматически.
