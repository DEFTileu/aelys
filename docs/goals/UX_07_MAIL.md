# Mail: читать и готовить ответ без лишних действий

```text
Работай в <repository-root>.
Цель: Mail: читать и готовить ответ без лишних действий.
Милestone: Phase 3 task 4: Mail import/drafts — UX-срез.

Прочти docs/goals/UX_RULES.md и docs/UX_RESEARCH.md, затем обязательные документы из AGENTS.md. Соблюдай их в течение всей цели. Владельцем уже разрешены UI/UX-переработка этого среза и до шести субагентов; делегируй только независимые файлы.

Переработай Mail как рабочий почтовый интерфейс: источник/аккаунт, поиск и список писем, reading pane, редактор draft. Поддержи импорт EML, текущий Gmail read/drafts, реальную пагинацию и ясный connect/disconnect state. Группируй переписки только при настоящем thread_id, не по догадке из subject. Plain text/HTML безопасны; произвольный HTML писем не исполняется. Не смешивай чтение письма с формой подключения. Отдельный draft и несохранённый текст не теряются при смене selection. Показать read-only/локальный draft/published Gmail draft как разные статусы. Отправка email не разрешена: не добавляй Send, не расширяй OAuth scopes и не называй публикацию черновика отправкой. Telegram Business не переписывать в этом срезе.

Критерии завершения:
Импортировать EML, найти письмо, открыть, написать/сохранить draft, reload без дублей. Смена письма/ошибка сети не теряет ответ. Пагинация/конфликт версии/отсутствующий Google client имеют честные состояния. Проверены XSS fixture и draft lifecycle, токены не видны. Live Gmail — только при уже настроенном аккаунте, без отправки писем.

Доведи реализацию до функционально доступной локальной версии; не заканчивай только планом или макетом. В конце дай короткий отчёт с файлами, командами и точными результатами тестов, browser screenshot, ограничениями и следующей целью. Не запускай следующую цель автоматически.
```
